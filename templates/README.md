# templates/

Put the firm's template DXF here as `CH-TEMPLATE.dxf`.
`c2b run --seed templates/CH-TEMPLATE.dxf`
(and `windows\C2B-run.bat` automatically) reuses its layers, text styles,
dimension style,
linetypes and legend, so generated drawings are identical in setup to hand-drawn
ones.

Template DXFs are not committed: they are firm property and change over time.
